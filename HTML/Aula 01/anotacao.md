## HTML - HyperText Markup Language
O HTML é uma lingugem de marcação de texto, ou seja, seu próposito é estruturar textualmente uma página da Web/Documento.

## Elementos ou tags
Para estruturar um documento HTML utilizamos tags/elementos, por exemplo, para indicar que um texto é um parágrafo utilizamos a tag <p>texto do parágrafo<p>, mas também existem tags "autofechantes" que não possuem fechamentos, como a tag <img> de imagem.

### Exemplos de tags:
 - p: Parágrafo
 - h1: Título Principal
 - h2: Título Secundário
